# HarnessFlow

## What This Is

Build a local developer tool that turns a PRD and a local Git repository into a
verified branch, optionally a GitHub PR. Support existing and empty repositories.
Codex is the first execution adapter. Preserve the existing YAML platform.

## Core Value

A developer can hand the harness a PRD and a repository, leave it to work through
bounded, resumable implementation and repair, then inspect a branch backed by
commit-bound checks and requirement-level judge evidence. The YAML workflow
platform remains a maintained foundation and demo, not the primary product.

## Requirements

The authoritative requirement IDs and release acceptance are in
[REQUIREMENTS.md](REQUIREMENTS.md). The local release includes PRD intake,
durable execution and controls, deterministic verification, independent review,
an explicit judge, a file-based CLI, and Codex/Claude Code entry-point skills.
Hosted tenancy and cloud deployment are deferred until the remaining local
follow-ups are addressed.

User decisions (2026-10-10): local developers; verified branch/PR; Codex first;
new and existing projects; routine decisions automatic; bounded resumable runs.
The user approved implementation and parallel agents.
