# HarnessFlow

Build a local developer tool that turns a PRD and a local Git repository into a
verified branch, optionally a GitHub PR. Support existing and empty repositories.
Codex is the first execution adapter. Preserve the existing YAML platform.

User decisions (2026-10-10): local developers; verified branch/PR; Codex first;
new and existing projects; routine decisions automatic; bounded resumable runs.
The user approved implementation and parallel agents.
